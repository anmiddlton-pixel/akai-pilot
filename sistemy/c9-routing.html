Шлюз с панелью управления открывает наружу только нужные сервисы компании — API автоматизации, сайт, удалённый стол, базу для подрядчика — через одну точку с проверкой на входе. Агенты AKCore⁠™ изучают журналы шлюза, находят аномалии и предлагают администратору варианты переключения маршрутов и резервных серверов. Каждое изменение применяет администратор.

Цели

Один контролируемый вход вместо открытых портов. По каждой аномалии — полная цепочка: «обнаружено → рекомендовано → применено администратором → проверено». Решение о каждом изменении остаётся за администратором.

Что вы получаете

Один контролируемый вход вместо открытых портов. Временный доступ — по одноразовой ссылке, запасные маршруты — наготове, каждое обращение — в журнале. По каждой аномалии — карточка с доказательствами из журналов, варианты действий и прогноз: сколько сеансов оборвётся и какие поля настройки не пройдут проверку. Цепочка статусов видна целиком.

Как работает

12 шагов процесса

Агенты работают под ролью наблюдателя, никогда не получают прав администратора и не видят содержимого трафика.

ОграниченияПока не подтверждены интерфейсы выгрузки журналов, состояния маршрутов и аудита, а также проверка черновика настройки без сохранения.

Пока не подтверждены интерфейсы выгрузки журналов, состояния маршрутов и аудита, а также проверка черновика настройки без сохранения. Без такой проверки прогноз по полям настройки неполный. Пороги детекторов и размеченная история инцидентов для эталонного набора не определены. Если слот ведёт к рабочему месту оператора, рекомендация уходит и владельцу АСУ ТП заказчика. Агенты никогда не пишут в АСУ ТП.
