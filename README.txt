AK.PILOT — akai.systems — статический сайт для размещения на сервере
=====================================================================

Сборка сгенерирована из канона GEN-MEDIA-AKSTORE-26.01 (rev22). Не править файлы руками —
изменения вносятся в канон и пересобираются (см. CLAUDE.md в папке проекта).

РАЗМЕЩЕНИЕ
----------
1. Загрузить всё содержимое этой папки в корень сайта (public_html / www / htdocs).
2. index.html должен открываться на корне домена: https://akai.systems/
3. Нужен HTTPS. Внешних зависимостей нет: шрифты и картинки лежат локально.
4. sitemap.xml, robots.txt и llms.txt рассчитаны на адрес https://akai.systems/.

ФОРМА ЗАЯВКИ (pilot.html)
-------------------------
- Заявки уходят на почту через сервис FormSubmit.co. Адрес — в js/config.js.
- FormSubmit требует ОДНОРАЗОВОЙ активации: при первой заявке на почту придёт письмо
  со ссылкой — перейти по ней один раз (проверить и «Спам»).
- Позже форму можно перевести на входящий вебхук Битрикс24.
